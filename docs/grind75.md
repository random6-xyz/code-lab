# Grind 75 Practice Set

This is the complete default 75-question Grind 75 plan, grouped by its original eight-week schedule. Each entry is an independent code-lab YAML problem with a project-native stdin/stdout contract and at least six grading cases.

Source: [Grind 75 by Tech Interview Handbook](https://www.techinterviewhandbook.org/grind75/). The title, difficulty, topic, duration, canonical problem URL, and week grouping are based on the official [QuestionGroups.json](https://github.com/yangshun/tech-interview-handbook/blob/main/apps/website/contents/_components/QuestionGroups.json). Problem statements and test cases here are adapted for code-lab and are not copied solutions.

All problem IDs use the `grind75-` prefix so the full set can coexist with the existing SWE practice set while retaining every Grind 75 entry, including canonical problems that appear in both collections.
